# Contrato de experiência

| Capacidade | Decisão |
| --- | --- |
| Navegação | Página única com âncoras para módulos; cabeçalho e menu permanecem consistentes. |
| Formulários | HTML nativo com `novalidate`; erro retorna ao painel com mensagem global. |
| Select/Data | Controles nativos, adequados ao escopo acadêmico e desktop. |
| Tabelas | HTML semântico; renderização completa adequada ao volume da demonstração. |
| Feedback | Flash message no topo após cada operação. |
| Exclusão | Não exposta na interface; baixa é a operação patrimonial segura. |
| API | Endpoints REST permanecem disponíveis para Postman. |
